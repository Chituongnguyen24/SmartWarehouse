# UI/UX Enterprise Design Guidelines - Anti-AI Tropes

This project follows enterprise-grade B2B logistics/WMS software design standards:
- **No decorative emojis** in headers, cards, tables, badges, or buttons.
- **No loud neon/multi-color gradients** or glowing outlines. Use flat surfaces with subtle 1px border (`#e2e8f0`) and clean elevation.
- **Accurate business terminology**: "Dự báo nhu cầu nhập kho" instead of "AI Co-pilot", "Chỉ số rủi ro bảo quản" instead of "ML Spoilage Index".
- **Balanced typography**: `font-weight: 600/700` for headings, `500` for labels, `400` for body. Do not overuse font-weight 800/900.
- **Standard radii**: 6px-10px for cards/buttons, max 12px for modals.
